# Лендинг «Захист UA» — індексація

## Что внутри
```
index.html            — сама страница
assets/js/config.js   — пиксель, токен бота, ID группы (менять здесь)
assets/img/*.webp     — все изображения
.nojekyll             — служебный файл для GitHub Pages, не удалять
```

## Как опубликовать на GitHub Pages (5 минут)
1. Распакуйте архив на компьютере.
2. Зайдите на github.com → зелёная кнопка **New** (новый репозиторий).
3. Название, например `zahyst-landing` → **Public** → **Create repository**.
4. На странице репозитория нажмите ссылку **uploading an existing file**.
5. Перетащите в окно **содержимое** распакованной папки (файл `index.html` и папку `assets`), а не сам zip. → **Commit changes**.
6. **Settings** → слева **Pages** → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → **Save**.
7. Через 1–2 минуты сверху появится ссылка вида `https://ВАШ-ЛОГИН.github.io/zahyst-landing/`.

## Проверка после публикации
- **Заявки:** оставьте тестовую заявку → она должна прийти в Telegram-группу.
  Если не пришла: бот должен быть добавлен в группу участником.
- **Пиксель:** Meta Events Manager → пиксель 1452823599154656 → **Test events**, откройте сайт и пройдите квиз.

## События пикселя
| Событие | Когда срабатывает |
|---|---|
| PageView | открытие страницы |
| ViewContent + QuizStart (custom) | первый ответ в квизе |
| QuizStep (custom) | каждый ответ квиза, с номером шага и ответом |
| QuizComplete (custom) | квиз пройден |
| ViewForm (custom) | человек доскроллил до формы |
| Lead | заявка успешно отправлена в Telegram |
| Contact | клик по любому номеру телефона |

Для оптимизации рекламы — событие **Lead**.

## Важно про токен бота
Токен лежит в `config.js` и виден любому, кто откроет код страницы. Это обычная практика для простых лендингов, но бот используйте **только** для заявок.
Если в группу пошёл спам: @BotFather → `/revoke` → новый токен вставьте в `config.js` и загрузите файл заново на GitHub.
